LAN 방 기본값 — 클라이언트의 비밀번호 칸이 방 이름/규칙이 됩니다

duel → 방 duel  ·  duel#1234 → 방 duel + 비밀번호 1234  ·  d#1#l=4000,t=300 → 규칙까지 지정  ·  #l=4000 → 기본방 + LP 4000  ·  빈칸 → 기본 방 이름
비밀번호 칸은 19자 제한이라 규칙은 짧은 키를 쓰세요 — l LP · h 패 · d 드로우 · t 초 · b 판수 · m 메인 · x 엑스트라 · s 사이드 · r MR · g 태그, ocg/tcg 는 그대로. 긴 옵션은 아래 기본값으로 두는 편이 좋습니다.

📥 금지목록 파일 내려받기 (ZIP)
📖 방 이름·규칙 넣는 법 (초보자용, 클릭해서 펼치기)
① 게임에서 할 일 — EDOPro 「LAN + AI 대전」 → IP <서버 주소>, 포트 7914 → 비밀번호 칸에 방 이름 입력 → 들어가기 → 덱 선택 → 준비.
② 비밀번호 칸을 비우면 모두 lobby 방에서 만납니다(가장 간단).
③ 여러 방은 이름을 적으면 됩니다 — duel / 친구들. 비밀번호를 걸려면 duel#1234.
④ 규칙까지 — 짧은 키로 d#1#l=4000,t=300 (방 d, 비번 1, LP 4000, 300초). 19자 제한이 있으니 긴 규칙은 아래 기본값으로.
⑤ 아래 기본값은 새로 만드는 방부터 적용됩니다(이미 만든 방은 그대로). 금지/제한을 고르면 게임의 금지/제한: N/A 대신 그 목록이 표시됩니다.
플레이어에게 보낼 문서 — 플레이어 안내서(GitHub)
⑥ 봇과 대전 — 비밀번호 칸에 bot 또는 b 를 넣으면 WindBot(레이즈문 AI)이 그 방에 자동 입장합니다. 봇 방은 덱 확인하지 않기가 자동으로 켜집니다(일반 방은 그대로). 다른 덱은 b:티아라멘츠, b:ABC 처럼 b:덱이름 으로 부르면 됩니다(아래 메뉴얼 표 참고). 서버 대전 모드라면 방 만들 때 Notes(설명) 칸에 bot / b:덱 을 적으세요(비면 봇이 오지 않음).**서버 대전 모드**에서는 방 만들 때 Notes(설명) 칸에 적으세요.
